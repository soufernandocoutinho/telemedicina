# NextGo Saúde - Página de vendas de telemedicina

Página institucional e comercial para divulgação e venda dos planos de telemedicina da **NextGo Saúde**, voltada a pessoas, famílias e empresas.

O projeto apresenta os planos, benefícios, modalidades de atendimento e opções de contratação, além de direcionar o visitante ao WhatsApp ou aos links oficiais de contratação. A página é operada pela **FC Soluções Digitais / Guia Panorama**, revenda autorizada dos planos NextGo Saúde.

## Sobre o sistema

O site permite:

- conhecer os planos de telemedicina disponíveis;
- comparar modalidades para pessoa física, família e empresas;
- visualizar benefícios e especialidades;
- acessar informações por meio de uma experiência responsiva;
- solicitar propostas ou iniciar contratações pelos canais oficiais;
- gerenciar consentimento de cookies e ferramentas de análise opcional.

## Tecnologias utilizadas

- **HTML5** para estruturação semântica do conteúdo;
- **CSS3** para identidade visual, componentes e responsividade;
- **Bootstrap 5.3** para layout e componentes responsivos;
- **JavaScript** para interações da página e gerenciamento de consentimento;
- **Google Analytics, Google Ads, Google Tag Manager, Meta Pixel e Cloudflare Web Analytics** para ferramentas de medição opcionais, ativadas mediante consentimento;
- **Schema.org (JSON-LD)** para dados estruturados voltados a mecanismos de busca.
